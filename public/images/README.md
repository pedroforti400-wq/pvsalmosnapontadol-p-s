# Ilustrações da página

Artes originais geradas para o projeto Salmos na Ponta do Lápis:

- `biblical-friends.webp`: grupo de personagens bíblicos infantis com crianças, livro e ovelhinha; fundo transparente.
- `child-writing.webp`: criança escrevendo com uma ovelhinha; contexto visual de vídeo e oferta.
- `biblical-garden.webp`: jardim bíblico com personagens, cidade ao fundo, nuvens e luz acolhedora.

São imagens ilustrativas, não fotografias de clientes, páginas reais do material ou prova de resultados. Não foram extraídas da referência. Os originais PNG permanecem preservados fora do repositório; estes arquivos WebP foram otimizados para a página. Configure as substituições em `src/config.js`.
